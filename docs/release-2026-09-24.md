# Release 2026-09-24

## Scope

Deployed the staged session-evaluation pipeline. Learner audio is evaluated for
pronunciation and fluency as it arrives, transcript quality is evaluated
independently, and the completed session combines both result sets into the final
evaluation.

The release also includes bounded speech-provider concurrency, durable evaluation
state, idempotent retries, stale-run fencing, and the outcome-led practice UI from
the preceding release.
